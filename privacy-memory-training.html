Политика конфиденциальности: RS Королевство памяти

Дата обновления: 28 ноября 2026 года

Приложение находится в разработке. Эта политика описывает согласованные функции и планируемую обработку данных. Сведения о планируемых компонентах приведены для описания принципов работы приложения.

1. Назначение приложения

Приложение содержит десять мини-игр для тренировки зрительной, пространственной, последовательной и звуковой памяти и внимания. Это развлекательный тренажёр, не предназначенный для диагностики или лечения заболеваний.

2. Игровые данные и резервные копии

Для работы игр локально обрабатываются выбранный язык (русский или английский), настройки звука и оформления, прохождение уровней, открытые игры, результаты партий, достижения, кубки, награды, выбранные помощники и их костюмы. Игровой прогресс хранится на устройстве и не предназначен для передачи рекламным сервисам. Игры и сохранение прогресса работают без подключения к интернету.

Пользователь может самостоятельно создать файл резервной копии и восстановить его на другом устройстве через системный выбор файла Android. Такой файл может содержать игровой прогресс и настройки. Передавая файл другому лицу или размещая его в облачном сервисе, пользователь самостоятельно выбирает способ передачи; приложение не требует регистрации и не предусматривает собственное облачное хранение копий.

3. Реклама и сетевые функции

В приложении запланирован один компактный рекламный баннер размером 320×50 внизу экрана, в том числе во время игры. Если объявление недоступно, рекламная область скрывается. Полноэкранные объявления, принудительные ролики, платные покупки и просмотр рекламы для продолжения игры не предусмотрены.

Для рекламной интеграции планируются Рекламная сеть Яндекса и медиация VK. Рекламные SDK могут обрабатывать технические сведения об устройстве и приложении, сетевые данные и рекламные идентификаторы в зависимости от их настроек, версии SDK и применимых разрешений. Объявления подбираются и предоставляются рекламными сервисами. Разработчик размещает рекламный блок и не выбирает вручную отдельные объявления для каждого пользователя. Технические данные используются для загрузки и показа рекламы, её измерения и работы рекламной инфраструктуры. Подробнее: политика конфиденциальности Яндекса, описание обработки данных Yandex Mobile Ads SDK, политика конфиденциальности VK. Яндекс AppMetrica не предусмотрена; отдельная аналитика использования приложения не планируется. Для загрузки рекламы требуется интернет; сами игры работают офлайн.

4. Разрешения, хранение и удаление

Для игровых функций не предусмотрен доступ к камере, микрофону, контактам или геолокации. Резервные копии выбираются и сохраняются через системный интерфейс Android без постоянного доступа ко всем файлам устройства. Локальные игровые данные могут быть удалены при удалении приложения или очистке его данных средствами Android. Созданные пользователем резервные файлы необходимо удалять отдельно в выбранном месте хранения.
