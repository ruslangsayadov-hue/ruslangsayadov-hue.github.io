Политика конфиденциальности: Астерия: задачи и заметки

Дата обновления: 26 ноября 2026 года

Политика описывает обработку данных с учётом функций приложения. Состав сторонних компонентов и доступные настройки могут различаться в зависимости от установленной версии.

Разработчик — Руслан Саядов. Связь: ruslangsayadov@gmail.com. Android-пакет приложения — ru.startasks.

Данные пользователя

Задачи, заметки, события календаря, выбранное имя, настройки и история заработанных звёзд хранятся в памяти устройства. Приложение не отправляет содержимое этих записей на сервер разработчика. Регистрация и учётная запись не требуются. Основные функции доступны без интернета.

Резервная копия создаётся по действию пользователя. Файл сохраняется в выбранное им место. При выборе облачного провайдера в системном окне Android файл передаёт этот провайдер. Пользователь самостоятельно управляет доступом к своей копии.

Статистика и ошибки

В приложении используется AppMetrica от Яндекса для статистики запусков, сеансов и технических ошибок. SDK может обрабатывать технические сведения об устройстве, версии Android и приложения, сетевом соединении, идентификаторах установки и рекламы, а также отчёты о сбоях. Обработка выполняется сервисом AppMetrica. Содержимое задач, заметок, календаря и введённое имя не добавляются приложением к аналитическим событиям.

Сбор точного местоположения через настройки SDK отключён. Приложение не запрашивает доступ к геопозиции. При сетевом соединении получатель запроса видит IP-адрес, по которому может определяться примерный регион.

Реклама

Единый утверждённый принцип монетизации RS Apps: если реклама включена, допускается только компактный баннер в нижней части экрана, не перекрывающий содержимое и элементы управления. Полноэкранные объявления, принудительные рекламные ролики и ожидание перед использованием приложения не предусмотрены. Для рекламы выбраны Рекламная сеть Яндекса и медиация VK; доступность рекламы зависит от версии приложения и её конфигурации.

Приложение поддерживает небольшой баннер внизу основных экранов. Для его загрузки используется Яндекс Mobile Ads SDK с медиацией VK Ads. Рекламные сервисы могут получать технические сведения об устройстве, рекламные идентификаторы, IP-адрес и данные о показах и взаимодействиях с рекламой. При ограничении рекламного идентификатора в Android доступ к нему определяется системными настройками.

При выключенной удалённой настройке приложение не запрашивает загрузку баннера. Полноэкранная и принудительная реклама не используется. Приложение не передаёт рекламным SDK тексты задач, заметок и календарных записей.

Приложение получает публичные настройки показа баннера с GitHub по HTTPS. Этот запрос не содержит пользовательских записей. GitHub получает обычные сетевые сведения о запросе, включая IP-адрес. Загруженные настройки не содержат исполняемый код.

Информация об обработке данных Яндексом: политика конфиденциальности Яндекса.

Разрешения

Доступ к интернету нужен для статистики, настроек рекламы и загрузки баннера. Разрешение на уведомления используется для напоминаний о задачах и событиях, которые пользователь настраивает сам. Получение события загрузки устройства позволяет восстановить расписание локальных напоминаний.

Удаление и обращения

Локальные записи можно удалять в приложении. Полная очистка доступна в настройках с отдельным подтверждением. Очистка данных приложения средствами Android также удаляет локальные записи. Экспортированные ранее файлы резервных копий при этом сохраняются; ими управляет сам пользователь.
